PodAM

PodAM is a security-focused personal data environment created by Inommarka.

It provides a simple web interface for creating a personal account, accessing a personal Pod, uploading data, viewing stored data, and downloading it when needed.

Access PodAM

🌐 PodAM Web Application

"Open PodAM" (https://reference-url-citation.invalid/0)

From the web application you can:

- Create an account
- Sign in
- Access your personal Pod
- Upload files
- View your uploaded data
- Download your data
- Sign out and return later

Create an Account

"Create a PodAM account" (https://reference-url-citation.invalid/1)

Select Create an account from the application and provide the requested account information.

🔐 Sign In

"Sign in to PodAM" (https://reference-url-citation.invalid/2)

Existing customers can use the same application to sign in and access their Pod.

7-Day Free Trial

New customer accounts currently begin with a 7-day free trial.

The trial allows users to experience the current PodAM environment before additional account and subscription capabilities are introduced.

⚠️ Important Trial Warning

PodAM is currently an early public release.

During the trial, do not upload sensitive, confidential, financial, identity, medical, or irreplaceable information.

Use test or non-sensitive data while evaluating the service.

The platform is actively being developed, and availability, functionality, and data persistence may change during this early release.

Current Capabilities

The current release includes:

- Customer account creation
- Customer authentication
- Personal Pod access
- 7-day trial access
- File upload
- File listing
- File download
- Data integrity verification
- Device-aware access control
- Persistent data handling

Additional capabilities are planned for future releases.

Product Status

Early public release — actively developing.

PodAM is publicly available so that people can experience the product and provide feedback while development continues.

Technology

PodAM is being developed using systems and security engineering technologies including:

- Rust
- Web applications and APIs
- Authentication and authorization
- Data integrity verification
- Persistent data handling
- Automated testing
- Cloud deployment infrastructure

The underlying implementation and deeper architecture are proprietary and are not published in this repository.
